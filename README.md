# Esrihel S. Monares - E-Portfolio (DCIT 26 Midterm)

React + Vite + Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```
Open the address Vite prints (usually http://localhost:5173).

## Edit your content
Everything on the site comes from `src/data.js`. Search for `TODO` and replace the
placeholders (email, social links, projects, education, experience).
Put your CV in `public/Monares-CV.pdf` so the Download CV buttons work.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. Go to vercel.com, choose Add New > Project, and import the repository.
3. Framework preset: Vite. Build command: `npm run build`. Output: `dist`.
4. Select Deploy, then open the Vercel URL in a private window to confirm it loads.
